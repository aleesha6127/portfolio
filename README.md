# ⚡ Aleesha Anas — Software Developer Portfolio

A modern, production-ready software developer portfolio built with **Python**, **Flask**, **HTML5**, **CSS3**, and **JavaScript**. This portfolio showcases my technical skills, software development projects, internships, certifications, and achievements through a clean, responsive, and interactive user experience.

- 🌑 Premium dark luxury user interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/aleesha6127/portfolio.git
cd portfolio
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

### Open in Your Browser

```
http://127.0.0.1:5000
```
