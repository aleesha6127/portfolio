# ⚡ Aleesha Anas — Software Developer Portfolio

A dark luxury, production-ready personal portfolio web application built with **Python**, **Flask**, **HTML5**, **CSS3**, and **JavaScript**.

---

## 🌟 Key Features

- **Dark Luxury Aesthetics**: Dark obsidian design system (`#06080E`) with gold gradients (`#F4B75E`), ambient lighting glows, and glassmorphism.
- **Interactive AI Copilot**: Python Flask backend chat API endpoint (`POST /api/copilot`) serving real-time answers about Aleesha's stack, experience, and projects.
- **Engineering Matrix Showcase**: Dual-column About section featuring core CS pillars and skill proficiency meters.
- **Minimal Work Experience Timeline**: Sleek, hover-responsive list detailing 3 software engineering internships.
- **5 Featured Case Studies**: Interactive project cards with live demo launches and modal detail popups.
- **Verified Accreditations & Honors**: Glowing badge cards highlighting NPTEL IIT Bombay/IIT Madras certification, Capital Infotech, ICMCTT-IV 2024 Award, and IRJAEM Journal publication.
- **High-Tech Contact Hub**: One-click email copy button with instant feedback, WhatsApp direct link, location badge, and interactive contact form.

## 🚀 Local Quickstart

### 1. Clone the Repository
```bash
git clone https://github.com/aleesha6127/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch Python App
```bash
python app.py
```

### 4. Open in Browser
Visit **`http://localhost:5000`** or **`http://127.0.0.1:5000`**.
